## Featured projects

### DVB-S2X Satellite Link Simulation

Simulation and performance analysis of a DVB-S2X satellite communication link under realistic physical-layer impairments.

The simulation includes:

* 8PSK, 16-APSK and 32-APSK
* DVB-S2X MODCODs
* Saleh TWTA nonlinear model
* Input Back-Off analysis
* Carrier Frequency Offset
* Sampling Clock Offset
* Phase noise
* PAPR
* BER / PER performance evaluation

`MATLAB • DVB-S2X • APSK • TWTA • Satellite PHY`

---

### OTFS vs OFDM in High-Mobility Channels

Link-level comparison of OTFS and OFDM under multipath propagation and high-Doppler conditions.

Main topics:

* Time-varying multipath channels
* Delay-Doppler representation
* Channel estimation
* Equalization
* LDPC coding
* BER / BLER analysis
* Performance under high mobility

`MATLAB • OTFS • OFDM • LDPC • Doppler • Delay-Doppler`

---

### OFDM + DVB-S2 LDPC Simulation

End-to-end coded OFDM communication chain using DVB-S2 LDPC codes.

The simulation includes:

* QAM modulation
* OFDM waveform generation
* AWGN and multipath channels
* LDPC encoding and decoding
* Eb/N0 sweeps
* BER analysis
* Coding-gain evaluation

`MATLAB • OFDM • DVB-S2 • LDPC • QAM`
